# Split profile concerns into focused pages

Keep the familiar profile shell while moving event registrations, discount
cards, and submitted receipts to their own routes. The account overview now
shows contact, home-organization, and reimbursement readiness without exposing
full bank details. Event add-on summaries use the recorded organization
currency and price only purchased units, never included entitlement. Mobile
detail navigation hands keyboard focus to one page heading and retains clear
spacing without fragment compatibility.
