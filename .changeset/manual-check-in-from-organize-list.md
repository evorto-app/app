# Check in attendees from the organize list

Organizers who can scan tickets now check in a confirmed attendee and their guests from the organize page, without scanning the ticket. A confirmation dialog shows how many guests can still check in and explains when check-in is not open, already done or not possible. The existing check-in rules still apply, including no self check-in. Every sign-up row on the organize page now shows its actions on a line below the name, so rows line up.
