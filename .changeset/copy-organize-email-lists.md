# Copy email address lists on the organize page

- let organizers copy the email addresses of the organizer/helper team, all attendees, checked-in attendees, or attendees not checked in with one click,
- include confirmed sign-ups only, remove duplicate addresses, and separate them with commas so the list pastes into any mail client,
- disable a copy action when its group is empty and confirm each copy with the number of addresses copied.
